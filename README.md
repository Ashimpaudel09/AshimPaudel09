## 🚀 Things I've built

### [E-Commerce Backend](https://github.com/Ashimpaudel09/Ecommerce-Backend)
A complete backend with products, cart, orders and payments. It uses version-based caching in Redis for product listings, and idempotency keys so the same order can never be paid twice. Payments run through the eSewa sandbox.
`TypeScript` `Express` `Redis` `PostgreSQL` `BullMQ`

### [JobFlow](https://github.com/Ashimpaudel09/JobFlow)
A job processing system built around multiple workers that pick up and run queued jobs, with Redis handling the queue. Organised as a Turborepo monorepo.
`TypeScript` `Node.js` `Express` `Redis` `PostgreSQL`

### [Crop Recommendation & Expense Tracking](https://github.com/Ashimpaudel09/crop-recommendation-system)
A full-stack farming platform with a Next.js frontend, a Node.js backend and a separate FastAPI service for ML predictions. The Random Forest and Logistic Regression models are written from scratch, with no scikit-learn, and their results are compared to improve recommendations. It also tracks farm expenses.
`Next.js` `Node.js` `FastAPI` `MongoDB` `Python`
